Architecture

From raw data to insight
in one unified pipeline

A single python run_pipeline.py orchestrates every phase from fetch to forecast.

01
🌐

Ingest & Validate

yfinance pulls daily OHLCV for 10 NIFTY 50 stocks back to January 2019. Validation checks OHLC integrity, removes negative prices, deduplicates, and forward-fills nulls. Results are written to PostgreSQL via SQLAlchemy with a full audit log.

02
⚙️

Engineer Features

50+ technical indicators are computed lag-safely — no future data leakage. Features include trend (SMA, EMA, DEMA), momentum (RSI, MACD, Stochastic), volatility (ATR, Bollinger), volume (OBV, relative volume), and calendar effects.

03
🏋

Train & Evaluate

9 model architectures are trained per ticker per horizon per task with 4-fold walk-forward cross-validation. MLflow logs every run. Best models are selected by directional accuracy for classification and MAE for regression, then saved as .joblib.

Model Registry

Each ticker is trained across 9 model types, 2 horizons (1-day, 5-day), and 2 tasks (regression, classification) for comprehensive coverage.
